# Проба на iPhone: сборка в Codemagic и установка через Sideloadly

Цель: проверить на вашем iPhone (iOS 18.7.1):
- P2 — шифрованную базу на iOS;
- P4 — уведомления и лимит очереди iOS;
- P5 — распознавание русской речи, в том числе на устройстве;
- P6 — скорость шифрования.

Время: около 30–40 минут в первый раз.

## Шаг 1. Подключить репозиторий к Codemagic (один раз)
1. Откройте https://codemagic.io/apps и войдите (через GitHub).
2. Нажмите **«Add application»**.
3. Выберите **GitHub**. Если Codemagic попросит доступ к репозиториям — нажмите «Install / Configure GitHub App» и дайте доступ **только к репозиторию `u-assistant`** («Only select repositories»).
4. Выберите репозиторий **`zhneo/u-assistant`**.
5. Тип проекта — **«Flutter App»**. Если предложат выбор между редактором и `codemagic.yaml` — выберите **`codemagic.yaml`** (файл уже лежит в репозитории).
6. Нажмите **«Finish: Add application»**.

## Шаг 2. Запустить сборку
1. В приложении нажмите **«Start new build»**.
2. Ветка — **`main`**, workflow — **«iOS — проба этапа 7 (без подписи)»**.
3. **«Start new build»**. Сборка идёт 10–20 минут и тратит бесплатные минуты (их 500 в месяц).
4. Когда сборка станет зелёной, откройте её и в разделе **Artifacts** скачайте **`ua_probe_unsigned.ipa`**.
5. Если сборка красная — скопируйте последние строки лога с ошибкой и пришлите в чат.

## Шаг 3. Установить на iPhone через Sideloadly
1. Подключите iPhone кабелем, разблокируйте его, на вопрос «Доверять этому компьютеру?» нажмите **«Доверять»**.
2. Откройте Sideloadly. В поле устройства должен появиться ваш iPhone.
3. Перетащите `ua_probe_unsigned.ipa` в окно Sideloadly (или нажмите на значок IPA и выберите файл).
4. В поле **Apple ID** введите свой Apple ID и нажмите **Start**. Пароль вы вводите сами в окне Sideloadly. Если включена двухфакторная проверка, введите код с телефона.
5. Дождитесь «Done».

## Шаг 4. Разрешить запуск на iPhone (один раз)
1. **«Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика»** → включить → перезагрузить телефон → после перезагрузки подтвердить «Включить» и ввести код телефона.
2. **«Настройки» → «Основные» → «VPN и управление устройством»** → ваш Apple ID → **«Доверять»**.
3. Откройте приложение **«UA Probe»**.

> Подпись бесплатного Apple ID действует 7 дней. Потом приложение перестанет открываться — для пробы этого достаточно.

## Шаг 5. Пройти пробы
| # | Действие | Что смотреть |
|---|---|---|
| 1 | Подождать 2 секунды после открытия | В журнале строка `P2 база: … cipher: chacha20 … ftsHit: 1` |
| 2 | **«1. Запросить разрешения»** → разрешить уведомления | В журнале `разрешение на уведомления: true` |
| 3 | **«2. Уведомление через 60 с»** → сразу заблокировать телефон или свернуть приложение | Через минуту приходит уведомление «U-Assistant: проба P4». Запомните, пришло ли оно вовремя |
| 4 | Вернуться в приложение → **«3. Проверить лимит очереди (70)»** | Строка `в очереди ОС: …` (ожидаем 64) |
| 5 | **«Проверить доступность и языки»** → разрешить микрофон и распознавание речи | Есть ли русская и казахская локали |
| 6 | **«Слушать (на устройстве)»** → сказать: «Завтра в девять утра напомни отправить отчёт руководителю» → **«Стоп»** | Итоговый текст или ошибка |
| 7 | Включить **авиарежим** → снова **«Слушать (на устройстве)»** с той же фразой | Работает ли без интернета |
| 8 | Выключить авиарежим → **«Слушать (любой режим)»** с той же фразой | Сравнить качество |
| 9 | **«Замерить»** в разделе P6, подождать до минуты | Строки `P6 …` |
| 10 | **«Скопировать отчёт»** → вставить в чат | Весь журнал придёт мне |

В отчёте только тестовые фразы и технические данные, личного там ничего нет.
