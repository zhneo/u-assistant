# U-Assistant — информационная архитектура (этап 3)

> Статус: **черновик на согласование**. Дата: 23.10.2026.
> Основание: [REQUIREMENTS.md](REQUIREMENTS.md) (согласовано), [DECISIONS.md](DECISIONS.md).
> **Обновление (этап 5, D-020):** вкладка «Финансы» переименована в «Деньги». Ниже старое название означает ту же вкладку.
> Здесь описаны разделы, экраны, навигация и связи между ними, то есть **что где находится и как туда попасть**. Как экраны выглядят (визуальные блоки, темы, состояния по 18 пунктам мастер-промпта) — на этапах 4–5 в `UI_SPECIFICATION.md`.

**Обозначения:** `SCR-xx` — экран, `SH-xx` — нижняя панель (bottom sheet), `DLG-xx` — диалог. В колонке «Тр.» указаны ID требований из REQUIREMENTS.md.

## 1. Принципы навигации

1. **Не больше 5 элементов в нижней панели** (FR-GEN-11): 4 вкладки + центральная кнопка «+».
2. **Вкладка = частый вопрос пользователя**, а не модуль базы данных:
   - «Что у меня сегодня?»
   - «Что мне нужно сделать?»
   - «Что с деньгами?»
   - «Где моя заметка?»
   Редкие модули (долги, курсы, журнал) находятся внутри разделов, а не в нижней панели.
3. **Создание — из одной точки.** Кнопка «+» открывает быстрое добавление любого типа. На экранах разделов есть контекстное «+» для своего типа: в проекте создаётся задача этого проекта, в категории — операция этой категории.
4. **Глубина ≤ 3 уровней** от вкладки до любого экрана просмотра (вкладка → список → запись). Связанные записи открываются поверх, «Назад» возвращает к исходной.
5. **Создание и правка** — нижняя панель для быстрых форм, которая разворачивается в полноэкранную форму для подробных полей. **Просмотр** — отдельный экран.
6. **Поиск** — иконка в верхней панели каждой вкладки, всегда в одном месте.
7. **Каждому жесту есть кнопка** (NFR-A11Y-06): свайп по строке дублируется меню «⋯».

### Почему именно так (решение D-015)

| Вариант | Вкладки | Плюсы | Минусы | Итог |
|---|---|---|---|---|
| **A (выбран)** | Сегодня · Дела · **[+]** · Финансы · Заметки | Каждая вкладка отвечает на частый вопрос. Финансы и дела равноправны. Заметки в 1 нажатие. Календарь — продолжение «Сегодня» (это и есть «план», D-007) | Календарь не на отдельной вкладке. Цели и привычки — на втором уровне в «Делах» | ✔ |
| B | Сегодня · Календарь · [+] · Финансы · Ещё | Календарь на виду | Задачи и заметки спрятаны в «Ещё». «Ещё» — свалка, которую считают ошибкой IA | ✗ |
| C | Задачи · Финансы · [+] · Заметки · Календарь | Модули на виду | Нет сводного экрана дня — теряется главная идея «одно место для всего» | ✗ |
| D | 5 вкладок без центральной кнопки | Больше разделов | Медленнее частые действия: нужно сначала выбрать раздел, потом «+» | ✗ |

## 3. Глобальные элементы

| Элемент | Где | Поведение | Тр. |
|---|---|---|---|
| Нижняя панель | Все экраны первого уровня вкладок | Скрывается на экранах записи и в формах. Повторное нажатие на активную вкладку — прокрутка вверх, затем возврат к корню вкладки | FR-GEN-11 |
| Центральная «+» | В нижней панели | Нажатие → SH-01. Долгое нажатие → шаблоны и закреплённые операции. Альтернатива долгому нажатию — пункт «Шаблоны» внутри SH-01 | FR-GEN-02, FR-FIN-09 |
| Верхняя панель вкладки | Корень каждой вкладки | Слева — заголовок. Справа — поиск (всегда) и меню «⋯» (разное по вкладкам). На «Сегодня» вместо «⋯» — настройки | FR-GEN-03 |
| Всплывающее «Отменить» | После удаления, завершения, массовых изменений | ~5 с; не перекрывает «+» | FR-GEN-07 |
| Баннер состояния | Верх экрана «Сегодня» и «Настроек» | Только важное: нет внешнего бэкапа N дней, автобэкап не удался, напоминания ненадёжны, нет курса валюты. Не больше одного баннера одновременно, по приоритету | FR-BAK-09, FR-BAK-13, FR-REM-04, FR-FIN-16 |
| Экран блокировки | Поверх всего при запуске и возврате | PIN + биометрия | FR-SEC-02 |

### Ярлыки приложения (вход снаружи)
- Долгое нажатие на иконку приложения (iOS Quick Actions / Android App Shortcuts): «Расход», «Задача», «Голос», «Заметка» → сразу открывается соответствующая форма. Приоритет — S [П].
- Уведомление → экран записи (задача, привычка, плановая операция, долг). Если включён PIN — сначала блокировка, затем запись.
- Открытие файла `.uabk` из «Файлов» или Telegram → SCR-89 Восстановление.
- Виджеты домашнего экрана — после v1 (REQUIREMENTS §3.3).

## 4. Разделы

Для каждого раздела: назначение, экраны, основные и дополнительные действия, переходы, связи, поиск и фильтры, настройки, пустые состояния, ошибки.

### 4.1 Сегодня

**Назначение.** Ответить на вопрос «что у меня сегодня и всё ли в порядке». Это «план дня» (D-007). Первая вкладка при запуске.

| Экран | Содержимое (сверху вниз) | Тр. |
|---|---|---|
| SCR-10 Сегодня | 1) Заголовок с датой + полоса недели (7 дней с индикаторами, нажатие на день → SCR-11 «день»). 2) Баннер состояния (если есть). 3) Блок «Деньги сегодня»: «Свободно до конца периода», траты сегодня, кнопка «Ожидают подтверждения (N)» → SCR-13. 4) Просроченные задачи (свёрнуты, если много). 5) Задачи на сегодня: с временем — по времени, без времени — по приоритету. 6) Привычки на сегодня с отметкой в 1 нажатие. 7) События системного календаря (если включено), только чтение. 8) Предстоящие платежи на 7 дней. 9) Кнопка микрофона (дублирует голос из «+») | FR-HAB-03, FR-FIN-20, FR-CAL-05, FR-VOI-01 |
| SCR-11 Календарь | Переключатель Месяц / Неделя / День. Фильтр типов (задачи, привычки, платежи, долги, дедлайны, системные события). Месяц — точки-индикаторы, под сеткой список выбранного дня. День — список по времени + «весь день» | FR-CAL-01…07 |
| SCR-12 Предстоящие | Список по дням на 7 / 14 / 30 дней: задачи, вхождения повторов, платежи, сроки долгов, дедлайны | FR-CAL-01 |
| SCR-13 Ожидают подтверждения | Плановые операции, дата которых наступила: «Подтвердить» (с правкой суммы), «Пропустить», «Перенести» | FR-FIN-18 |
| SCR-14 Активность | Лента журнала действий, фильтр по типу и периоду; сводка недели (C) | FR-HIS-01, FR-HIS-05 |

- **Основные действия:** отметить задачу, отметить привычку, подтвердить платёж, перенести задачу (меню строки), открыть день в календаре, голос.
- **Дополнительные:** скрыть или показать блоки «Сегодня» (настройка), открыть активность (меню «⋯» на SCR-11/12 и ссылка внизу SCR-10).
- **Переходы:** строка задачи → SCR-21; привычка → SCR-27; платёж → SCR-39 или SCR-13; событие системного календаря → системное приложение календаря; «Свободно» → SCR-30.
- **Связи:** агрегирует задачи, привычки, плановые операции, бюджеты, системный календарь.
- **Поиск и фильтры:** глобальный поиск; на SCR-11 — фильтр типов.
- **Настройки:** какие блоки показывать на «Сегодня», первый день недели, системные календари (SCR-83).
- **Пустое состояние:** «На сегодня ничего не запланировано» + две кнопки: «Добавить задачу» и «Записать расход». В первые дни — карточка-подсказка про «+» и голос.
- **Ошибки:** нет доступа к системному календарю → блок скрыт, в SCR-83 подсказка «разрешить». Нет курса валюты → блок «Деньги» показывает «неполный итог» со ссылкой на SCR-44.

### 4.2 Дела

**Назначение.** Управлять всем, что нужно сделать или к чему стремиться: задачи, проекты, цели, привычки. Сегменты вверху экрана переключают 4 списка без смены вкладки.

| Экран | Содержимое | Тр. |
|---|---|---|
| SCR-20 Задачи | Чипы-списки: Входящие · Сегодня · Предстоящие · Все · Выполненные. Строка: чекбокс, название, дата/время, дедлайн, проект, приоритет, иконки (повтор, напоминание, подзадачи 2/5, связанная заметка). Группировка по дате или проекту | FR-TSK-03 |
| SCR-21 Задача | Название, статус, дата, дедлайн, приоритет, проект, цель, теги, напоминания, повтор, подзадачи, описание, связанные записи, история изменений (свёрнута) | FR-TSK-01…08 |
| SCR-22 Проекты | Активные (прогресс, срок, число задач), затем приостановленные; завершённые и архив — в фильтре | FR-PRJ-01 |
| SCR-23 Проект | Шапка: прогресс, срок, цель. Задачи (активные → выполненные свёрнуты), заметки, история. «+» создаёт задачу в проекте | FR-PRJ-02…03 |
| SCR-24 Цели | Карточки целей с прогрессом и типом; фильтр по статусу | FR-GOL-01 |
| SCR-25 Цель | Прогресс, критерий, прогноз (для накопительной — «нужно в месяц»), связанные проекты, задачи, привычки, счета, заметки; «Обновить значение» для количественной | FR-GOL-02…04 |
| SCR-26 Привычки | Список с отметкой сегодняшнего дня и текущей серией | FR-HAB-01…02 |
| SCR-27 Привычка | Календарь отметок, текущая и лучшая серия, % за 30 дней, расписание, напоминание, пауза | FR-HAB-02, FR-HAB-04 |
| SCR-28 Повторяющиеся задачи | Все серии: правило, следующая дата; пауза, возобновление, завершение | FR-TSK-06 |

- **Основные действия:** создать задачу (контекстное «+» с учётом текущего списка или проекта), выполнить, перенести, открыть.
- **Дополнительные:** массовый выбор (FR-GEN-10), сортировка, группировка, «Повторяющиеся задачи» (меню «⋯»), отмена или пропуск повтора, завершение проекта с диалогом DLG-03.
- **Переходы:** задача → проект, цель, заметка, связанная операция; цель → счета (SCR-35), проекты, привычки; проект → цель.
- **Поиск и фильтры:** глобальный поиск + фильтры списка: статус, приоритет, проект, тег, дата, дедлайн (FR-TSK-03). Для проектов и целей — фильтр статуса.
- **Настройки:** время напоминания по умолчанию, первый день недели (SCR-83).
- **Пустые состояния:**
  - Входящие: «Сюда попадают задачи без даты и проекта», кнопка «Добавить».
  - Проекты: «Проект — это результат из нескольких задач. Например, «Подготовить диплом»».
  - Цели: «Цель — то, к чему вы идёте. Её прогресс собирается из задач, проектов или накоплений».
  - Привычки: пример + «Создать привычку».
- **Ошибки:** нельзя сохранить задачу без названия — подсветка поля. Перенос повторяющейся задачи по расписанию → DLG-02 «Только эта / Изменить правило».

### 4.3 Быстрое добавление (+)

**Назначение.** Записать что угодно за несколько секунд из любой вкладки.

| Элемент | Поведение | Тр. |
|---|---|---|
| SH-01 Меню типов | 6 крупных кнопок: Расход, Доход, Перевод, Задача, Заметка, Голос. Внизу — строка «Шаблоны» (закреплённые операции) | FR-GEN-02 |
| SH-02 Операция | Сумма с клавиатурой-калькулятором (фокус сразу) → чипы последних категорий → счёт (последний) → дата (сегодня) → «Сохранить». «Подробнее» разворачивает полный экран (описание, теги, связь с задачей, время) | FR-FIN-05…06, S1–S2 |
| SH-03 Перевод | Откуда → Куда → сумма (вторая сумма при разных валютах) → «Сохранить»; «Подробнее» — комиссия, описание, дата | FR-FIN-07, S3 |
| SH-04 Задача | Название (фокус) → чипы: Сегодня / Завтра / Дата, Напомнить, Проект, Приоритет → «Сохранить»; «Подробнее» — полный экран. Чип «Напомнить» одним нажатием ставит напоминание на время задачи, а для задачи без времени — на время по умолчанию (FR-SET-04, 09:00); повторное нажатие открывает выбор времени | FR-TSK-01, S4 |
| Сохранение с клавиатуры | Кнопка «Готово» на клавиатуре в SH-02…04 сохраняет запись, если обязательное поле заполнено | S1–S4 |
| Заметка | Сразу SCR-52, курсор в тексте | S6 |
| Голос | SCR-60…63 (§4.6) | FR-VOI |

- **Контекст:** «+» на экране проекта, категории или счёта предзаполняет соответствующее поле.
- **Ошибки:** сумма 0 или пустая — кнопка «Сохранить» неактивна с подсказкой. Нет ни одного счёта — предложение создать «Наличные» прямо в форме.

### 4.4 Финансы

**Назначение.** Ответить на вопросы «сколько у меня денег, куда они уходят, сколько можно потратить» и вести все финансовые записи. Сегменты: **Обзор · Операции · Аналитика**. Остальные экраны открываются из «Обзора» или из меню «⋯».

| Экран | Содержимое | Тр. |
|---|---|---|
| SCR-30 Обзор | 1) Общий баланс (базовая валюта, дата курса, пометка «неполный»). 2) «Свободно до конца периода». 3) Ожидают подтверждения (если есть). 4) Счета — горизонтальная лента карточек → SCR-34. 5) Бюджеты — до 3 ближайших к лимиту → SCR-36. 6) Предстоящие платежи на 7 дней → SCR-38. 7) Долги: «мне должны / я должен» → SCR-40 (скрыт, если долгов нет). 8) Накопительные цели → SCR-25. 9) Последние операции → SCR-31 | FR-FIN-20, §6.3 |
| SCR-31 Операции | Группировка по дням с итогом дня; панель фильтров: период, тип, счёт, категория, тег, сумма, текст; сортировка; массовый выбор | FR-FIN-11, FR-GEN-10 |
| SCR-32 Операция | Все поля, связанная задача или долг, для перевода — обе стороны, история изменений; «Дублировать», «Сделать шаблоном», «Удалить» | FR-FIN-05…10, FR-HIS-02 |
| SCR-33 Аналитика | Выбор периода вверху (месяц ‹ ›, произвольный). Вкладки: **Структура** (кольцо + список категорий → подкатегории), **Динамика** (столбцы доходы/расходы, линия баланса), **Сравнение** (период к периоду), **Бюджеты** (план/факт). Нажатие на элемент → SCR-31 с фильтром | FR-FIN-29…36 |
| SCR-34 Счета | Группы по типу; итог; архивные — в фильтре; порядок перетаскиванием и кнопками | FR-FIN-01 |
| SCR-35 Счёт | Баланс, валюта, флаги, операции счёта, «Корректировать баланс», «Перевести», «В архив» | FR-FIN-01…04 |
| SCR-36 / 37 Бюджеты / Бюджет | Список с прогресс-барами; экран: потрачено / лимит / осталось, дневной темп, прогноз, операции бюджета | FR-FIN-21…24 |

| SCR-47 Экспорт CSV | Период, фильтры, разделитель → системное «Поделиться» | FR-FIN-37 |

- **Переходы:**
  - аналитика → операции с фильтром;
  - счёт → его операции;
  - бюджет → его операции;
  - операция → задача, долг, правило;
  - накопительная цель → «Дела» SCR-25.
- **Связи:** счета ↔ накопительные цели; операции ↔ задачи; регулярные платежи ↔ напоминания и календарь; долги ↔ напоминания.
- **Поиск и фильтры:** глобальный поиск по описанию, сумме, категории, счёту; фильтры SCR-31; период в SCR-33.
- **Настройки:** базовая валюта, день начала финансового месяца, уведомления бюджета (SCR-82, SCR-84).
- **Пустые состояния:**
  - нет счетов → «Создайте первый счёт, например «Наличные»»;
  - нет операций → «Запишите первый расход — это займёт 3 секунды» + кнопка;
  - аналитика без данных → объяснение, что появится, и ссылка на запись операции;
  - нет бюджетов → пример «Продукты — 100 000 ₸ в месяц».
- **Ошибки:**
  - нет курса для валюты → «неполный итог» + переход к SCR-44;
  - удаление счёта или категории с операциями → DLG-04 с выбором переноса;
  - импорт: неверная кодировка или колонки → понятная ошибка с номером строки, база не изменена (AC-15).

### 4.6 Голосовой ввод

**Назначение.** Записать несколько дел и трат одной фразой с обязательной проверкой.

```

   ▼                                ▼                                    ▼                                       ▼
 выход без изменений             выход без изменений                 выход без изменений (DLG-05)        к «Сегодня» или к записи
```

| Экран | Содержимое | Тр. |
|---|---|---|

- **Настройки:** SCR-86 (режим «только на устройстве», история текстов, словари синонимов SCR-87).

## 8. Проверка IA по ключевым сценариям

Целевые значения из REQUIREMENTS §4. Подсчёт — для опытного пользователя от корня любой вкладки.

| Сценарий | Путь | Нажатий | Цель |
|---|---|---|---|
| S1 Расход (последняя категория) | «+» → Расход → сумма → Сохранить (категория и счёт уже предвыбраны) | 3 + ввод | ≤ 3 ✔ |
| S2 Доход | «+» → Доход → сумма → чип категории → Сохранить | 4 + ввод | ≤ 4 ✔ |
| S3 Перевод | «+» → Перевод → откуда → куда → сумма → Сохранить | 5 + ввод | ≤ 5 ✔ |
| S4 Задача на завтра с напоминанием | «+» → Задача → название → «Завтра» → «Напомнить» (сразу ставит время по умолчанию, FR-SET-04) → Сохранить | 5 + ввод | ≤ 5 ✔ (другое время — +1–2 нажатия) |
| S5 Перенос задачи | Строка задачи «⋯» (или свайп) → «Завтра» | 2 | ≤ 3 ✔ |
| S6 Заметка | «+» → Заметка | 2 + ввод | ≤ 2 ✔ |
| S7 Голос | Микрофон на «Сегодня» (или «+» → Голос) → речь → Готово → Разобрать → Сохранить всё | 4–5 | — ✔ |
| S8 Найти операцию | Поиск → запрос | 1 + ввод | ≤ 2 ✔ |
| S9 Бюджет на продукты | Финансы → карточка бюджета на «Обзоре» | 1–2 | ≤ 2 ✔ (если бюджет в топ-3; иначе Финансы → «⋯» → Бюджеты → бюджет = 3) |
| S10 Drill-down | Нажатие на сегмент диаграммы | 1 | 1 ✔ |
| S11 Привычка | Отметка на «Сегодня» | 1 | 1 ✔ |
